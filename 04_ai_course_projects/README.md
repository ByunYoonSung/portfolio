# AI Course Projects – Data Pipeline & Exploratory Analysis

본 저장소는 실제 데이터를 기반으로 **전처리 → 학습용 데이터 분리 → 탐색적 분석 → 시각화**의 과정을 Python으로 구현한 프로젝트 모음입니다.  
모델링 성능 자체보다는 **데이터 품질 이해와 파이프라인 구성 능력**에 중점을 두었으며, 이는 AX/DX 직무에서 필요한 **데이터 흐름 설계 역량**과 직접 연결됩니다.

---

## 프로젝트 구성

### 1. Project1.ipynb
- **주제**: 데이터 전처리 및 기초 통계 분석  
- **내용**:  
  - 결측값 처리 및 표준화(StandardScaler)  
  - 변수 분포 시각화, 상관관계 분석  
  - 분류/회귀 모델 적용을 위한 기반 데이터셋 구축  
- **연결성**: 금융/마케팅 데이터에서의 **데이터 정제 및 사전 분석 과정**과 동일  

---

### 2. Project2.ipynb
- **주제**: 데이터 분할 및 시각화  
- **내용**:  
  - train_test_split으로 학습/검증 데이터 분리  
  - matplotlib, seaborn 활용 분포 및 트렌드 시각화  
  - 데이터 구조 및 특성에 대한 직관적 이해 제공  
- **연결성**: **거래 로그, 고객 행동 데이터 분석**에 필요한 EDA 프로세스와 유사  

---

## 직무 연관성

본 프로젝트는 단순 과제를 넘어, **데이터 기반 의사결정과 분석 설계의 기본**을 체득한 경험입니다.  
- **데이터 전처리 및 품질 관리**: 금융 거래 데이터, 로그 데이터 정제와 직접 연결  
- **탐색적 데이터 분석(EDA)**: 고객 행동 분석, 이상치 탐지, 서비스 개선 인사이트 도출에 필수  
- **데이터 파이프라인 구축 경험**: AX/DX 프로젝트에서 요구되는 end-to-end 흐름 이해
