# Coding-Based Experimental Data Analysis

본 저장소는 4개의 실험 데이터를 기반으로 작성된 Python 분석 코드 및 보고서 모음입니다.  
각 프로젝트는 **실험 데이터 처리 → 모델 피팅 → 시각화 → 통계적 해석**의 과정을 거치며, 복잡한 신호와 패턴을 정량적으로 분석하는 데 초점을 맞췄습니다.  
이는 실제 산업 및 금융 환경에서 요구되는 **데이터 처리·시스템 최적화 역량**과 연결됩니다.

---

## 실험 구성

### 1. Chaotic Pendulum
- **주제**: 비선형 동역학계에서의 상전이 및 Chaotic Behavior 분석
- **내용**:  
  - 운동방정식 모델링 및 감쇠 진동 분석  
  - Q-factor, 자유에너지, 임계지수 계산  
  - Poincaré plot, Phase diagram 시각화  
- **연결성**: 복잡계 모델링 및 패턴 인식 → **금융 데이터 변동성 해석·리스크 모델링 역량**과 연계

---

### 2. Lock-in Detection & Hall Effect
- **주제**: 신호 대 잡음비 향상을 위한 Lock-in 기법과 홀 전압 분석
- **내용**:  
  - curve_fit 기반 모델 피팅  
  - Hall coefficient 측정 및 전도도 계산  
  - 실험 신호 정량화 및 선형성 검증  
- **연결성**: **노이즈 제거 및 신호 정제** 경험 → 대규모 거래 로그나 이상 거래 탐지에서 데이터 정제와 유사

---

### 3. Optical Tweezer
- **주제**: 입자 위치 변화를 통한 힘 분석
- **내용**:  
  - 변위 데이터 시계열 분석  
  - 복원력 상수(k) 산출  
  - 확률 분포 및 피크 검출  
- **연결성**: **시계열 데이터 처리·피크 탐지** → 거래량 변동, 실시간 로그 이벤트 분석에 적용 가능

---

### 4. Single Photon Interference
- **주제**: 단일광자 간섭 실험을 통한 패턴 분석
- **내용**:  
  - 센서 기반 영상 데이터 시각화  
  - numpy 기반 통계 분석  
  - 간섭무늬 피치·주기 계산  
- **연결성**: **영상·패턴 기반 데이터 추출** → 사용자 행동 패턴 분석, 인터페이스 데이터 처리와 연결

---

## 방향성
본 프로젝트는 다양한 데이터를 코딩 기반으로 정량 분석한 사례입니다.  
입사 후에는 이러한 데이터 분석 및 모델링 경험을 기반으로, **BC카드 AX/DX 백엔드 및 데이터 인프라 고도화**에 기여하여  
고객에게 **더 안전하고 편리한 금융 경험**을 제공하는 데 힘쓰겠습니다.
