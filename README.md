# AX/DX-Oriented Data & AI Portfolio – Byun Yoon Sung

안녕하세요, **BC카드 AX/DX 분야 지원자 변윤성**입니다.  
저는 복잡한 데이터를 분석하고, 새로운 기술을 빠르게 학습하여 **실제 서비스와 시스템 혁신으로 연결**하는 것을 강점으로 삼고 있습니다.  
이 포트폴리오는 대학에서 수행한 다양한 프로젝트를 통해 쌓아온 **데이터 분석, AI 활용, 사용자 경험 개선 역량**을 보여줍니다.  

---

## Projects

### 1. intermediate_physics_lab  
주제: 중급물리실험 (4개 실험)  
- **Chaotic Pendulum**: 비선형 동역학 데이터 분석  
- **Lock-in & Hall Effect**: 잡음 제거 및 전기 신호 분석  
- **Optical Tweezer**: 미세 입자 위치 데이터 처리 및 힘 분석  
- **Single Photon Interference**: 영상 기반 패턴 분석  
**연결성**: 복잡한 데이터를 **Python 기반 자동화 파이프라인**으로 처리하여 효율과 정확성을 동시에 개선 → DX의 데이터 인프라 최적화 역량과 직결  

---

### 2. astro_data_analysis  
주제: M74, M77 은하 분광 데이터 처리  
- FITS 데이터 전처리(flat/dark 보정) 및 시각화  
- 파장별 세기 해석으로 은하 중심 특성 도출  
**연결성**: **비정형 대규모 데이터 처리 경험** → 금융 데이터 로그, 결제 트랜잭션 분석과 유사한 데이터 처리 과정  

---

### 3. quantum_circuit_simulation  
주제: Qiskit 기반 양자회로 시뮬레이션  
- 큐비트 얽힘, 펄스 스케줄링, 시뮬레이션 구현  
- 추상적 수학 모델을 코드로 변환하여 실험 설계  
**연결성**: **새로운 기술 학습·적용력**을 기반으로 신기술을 팀 내 공유 → AX/DX 프로젝트에서 **민첩한 기술 도입과 협업 역량**에 해당  

---

### 4. ai_course_projects  
주제: 인공지능 과목 프로젝트  
- 나스닥 차트 데이터를 활용한 LSTM 기반 예측 실습  
- pandas, scikit-learn, seaborn으로 탐색적 데이터 분석  
**연결성**: 금융 데이터 분석과 AI 응용 경험을 통해 **맞춤형 서비스, 리스크 관리** 등 AX/DX의 실제 활용 영역과 직접 연결
