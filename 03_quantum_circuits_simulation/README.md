# Qiskit Practice Notebooks – Quantum Circuit Simulation

본 저장소는 Python 기반 Qiskit을 활용하여 **양자 회로 설계 → 시뮬레이션 → 결과 해석**의 과정을 정리한 프로젝트 모음입니다.  
복잡한 수학 모델을 코드로 구현하고, 시뮬레이터·노이즈 모델·펄스 제어 등을 실습하며 **데이터 처리 파이프라인 구축과 시뮬레이션 기반 검증 역량**을 키웠습니다.  
이는 AX/DX 직무에서 요구되는 **신기술 학습 능력·복잡한 시스템 이해·효율적 자원 활용**과 연결됩니다.

## 직무와의 연결점

- 복잡한 시스템 시뮬레이션 경험  
  → 금융 데이터의 불확실성과 대규모 트랜잭션 흐름을 모델링·테스트하는 능력으로 확장 가능  
- 데이터 파이프라인 엔드투엔드 경험  
  → 회로 설계 → 실행 → 결과 해석 과정이 AX/DX에서의 서비스 개발 프로세스와 유사  
- 신기술 학습 및 적용 역량  
  → 최신 툴(Qiskit, IBM Quantum)을 빠르게 학습·실습, 팀 내 공유 가능  
- 통계·선형대수 기반 사고력  
  → 금융 AI·리스크 분석·최적화 알고리즘 구현의 기반 역량과 직결
