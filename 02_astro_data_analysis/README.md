# Spectral Data Analysis – M74 / M77

본 저장소는 은하 M74, M77의 분광 데이터를 활용하여 **전처리 → 시각화 → 해석**의 전 과정을 코드로 구현한 프로젝트입니다.  
노이즈 제거, 파장 스펙트럼 분석, 특성 추출을 통해 복잡한 데이터를 정제하고 인사이트를 도출하는 과정을 담고 있습니다.  
이는 금융 및 산업 데이터 처리 과정에서 요구되는 **데이터 클렌징·피처 추출·패턴 분석 역량**과 연결됩니다.

---

## 프로젝트 개요

- **분석 대상**: 은하 M74, M77의 분광 데이터  
- **분석 목표**: 파장별 세기 분포 추출, 주요 스펙트럼 라인(feature) 식별 및 해석  
- **접근 방식**: FITS 데이터 전처리 → 시각화 → 특성(feature) 기반 해석

## 실무 연관성

이 프로젝트는 과학적 데이터를 다루지만, 과정 자체는 **AX/DX 데이터 분석 업무**와 직접 연결됩니다.

- **데이터 전처리 역량**: Flat/Dark 보정 → 금융 로그/거래 데이터 클렌징  
- **시각화 기반 피처 추출**: 스펙트럼 선 확인 → 이상 거래 탐지, 고객 행동 패턴 분석  
- **도메인 지식 결합**: 물리적 맥락을 데이터에 적용 → 금융에서도 **리스크 해석·수요 예측**과 같은 응용 가능  
- **엔드투엔드 파이프라인 경험**: 데이터 수집 → 정제 → 시각화 → 해석의 전 과정을 수행 → **DX 프로젝트 실행 프로세스와 동일**  

---

## 방향성

본 프로젝트는 관측 데이터의 노이즈 제거와 패턴 분석을 통해 의미 있는 결과를 도출한 사례입니다.  
이 경험을 기반으로, 금융 데이터 환경에서도 **정제·분석·시각화·해석까지의 전 과정을 수행하는 데이터 엔지니어링 역량**을 발휘하여,  
BC카드의 **AX/DX 인프라 고도화와 고객 중심 서비스 혁신**에 기여하고자 합니다.
